# 女高模拟器

附中校园生活养成原型，当前版本 **0.6.1 · 特质完善**。

从高一九月玩到高三六月：高一探索兴趣，高二完成共同项目并试验生活方式，高三在有限精力中取舍，最后生成包含学业、关系、作品、传闻与状态的毕业画像。八名人物暂用原有称呼，完整人物线仍会继续扩写。

## 开始试玩

- 单文件版：下载“女高模拟器-v0.6.1.html”，用浏览器打开，无需联网。
- 源码版：完整解压项目，打开根目录 `index.html`；不要只移动这个文件。
- 选择后自动保存，也可导出JSON。浏览器限制本地文件存储时，请使用导出、导入。
- 0.6.1只接受本版本重放存档，使用独立存档键，不读取或覆盖旧版键。旧存档请用对应旧版本打开。

## 当前规则

| 项目 | 规则 |
| --- | --- |
| 初始属性 | 学力、表达、体能、创造、外貌共用40点；每项0～20整数，允许极端偏科 |
| 能力成长 | 前四项每4经验升1点，上限30；每学期每项最多升3点；普通上课不免费赠送学力 |
| 外貌 | 单独显示，普通练习不增长；永久变化预留在初始值±2内；用于出镜等特殊场合，不直接换信任 |
| 家境与状态 | 家境不占属性点；零花钱、精力、压力独立记录 |
| 透支 | 精力不足仍行动时，缺口转成压力；压力溢出时继续损耗精力 |
| 判定 | 2d6加能力、状态、准备、特质和情境修正；结果显示原因 |
| 考试 | 月考一次策略，重要考试再加一次临场选择；显示预估与成绩构成 |
| 人物 | 关系与信任分开；八名人物有不同初遇，不在介绍后立即重复对话 |
| 生活习惯 | 高二设置学习、放学后、恢复三类方式；高三锁两项，只留有限微调 |
| 校园传闻 | 由真实经历触发，进入论坛并在后续对话中回收 |
| 毕业档案 | 汇总路线、能力、习惯、项目、关系、传闻、特质和遗憾，可下载PNG |

## 0.6.1：特质有实际用途，也可以后天形成

60项普通特质都增加类型与基础作用说明：性格、技能、兴趣、生活、网络、命运。类型说明“它是什么”；“可成长”“可后天形成”另作功能标识。

基础作用主要是相关领域判定修正，或按月恢复少量精力、压力。一次判定的正向普通特质修正合计最多+2，负向修正另算；月间特质恢复按资源分别封顶6，不免费赠送能力经验。有额外消耗的特质在当月首次真实发挥时支付，成绩预测不扣资源。

欧皇是固定+1，不暗改骰子；非酋是固定-1，失败后复盘该项能力经验+1，每月最多2次。外貌不能练习成长，因此外貌失败改为压力-2，共用这2次额度。

六项成长特质仍为：癫佬、电波、社恐、吉他手、完美主义、冰山。专属做法从人物交流扩展到适合的学习、项目、创作、音乐、比赛和表演事件，仍**替换一个允许替换的正常选项**，不继承原选项收益；安全回应和考试、路线等关键决定受保护。

同一特质每个自然月最多成长一次，跨4个月到Lv.2、跨8个月到Lv.3。失败仍有真实后果。癫佬保持战斗脑、决斗和“砍断、切开、剁碎”的气质。

没有在开局选到素材，也可从普通人物互动或假期中的“试一种自己的做法”进入自选练习。它取代本次相处或假期安排，不叠加原行动收益，也不是每月强制弹出的额外菜单。六项成长特质均有不要求先持有特质的普通练习。

- 明确相关行为至少跨4个不同月份；最早高一下3月（日历索引6）询问是否形成。
- 本局最多后天获得2项，不占用或替换原来的3项开局特质。
- 可以接受，或无惩罚暂缓至少3个月；每月最多询问一次。
- 获得后从Lv.1、0成长经验开始，形成前记录不折算为熟练度。
- 不从一次休息、独处、上网或笼统标签推断性格；“社恐”等是可拒绝的游戏标签，不是心理诊断。

## 当前唯一开放的隐藏角色

**癫佬＋电波 → 古明地恋**。两项各至少4个月成长，两者实际使用月份的并集至少12个月，覆盖4名人物、3类场景，并至少有同一人物成功接住过两种表达；最早高二寒假1月（日历索引16）。同月分别使用两项，只算一个合成所需月份。

条件满足后可以接受或暂缓至少2个月。合成后来源仍显示在档案：社交专属选项由古明地恋接管，学习、项目等普通活动中的来源做法及基础作用继续保留；来源不能再次用于合成。隐藏特质仍承担资源与失败代价。

其他隐藏角色本版不开放，不出现在正常界面、合成、毕业结果和调试入口；旧样板仅保留在开发数据中。本版没有新增真人映射。这是“60项基础作用＋6项成长＋1个隐藏角色”，不是60条独立剧情。

## 建议重点试玩

1. 比较不同类别的开局特质，观察判定、状态与说明是否一致。
2. 开局只选癫佬或电波之一，通过明确练习形成另一个，检查自然养成是否可行。
3. 记录后天形成和古明地恋出现的月份；同月重复选择应不能缩短门槛，暂缓不应丢进度。
4. 比较普通帮助、安全倾听与专属活动，确认机会成本成立，合成后活动玩法仍在。
5. 对比学力0、8、20的考试与精力30/10、压力70/90的阈值反馈。
6. 留意人物重复感，以及高二项目、高三取舍和毕业档案的回收。
7. 试验结果页读档、JSON导入导出及毕业PNG导出。

## 自动检查与打包

需要Node.js，无第三方运行依赖：

```bash
npm test
npm run build
npm run test:standalone
```

测试覆盖规则边界、完整三年路线、后天形成自然流程、中途/毕业存档重放与源码/单文件一致性；以命令输出为准。构建在项目外的 `release/` 输出单文件HTML；源码无需构建。

可选真实浏览器脚本 `tools/browser-check.js` 需要另行安装Playwright与Chromium，不属于 `npm test`。规则模拟不能代替桌面和手机视觉验收。

底部调试面板可跳月份、补齐古明地恋素材；使用后标记为调试局，不覆盖正常存档。状态接口为 `GameDebug.getState()`、`GameDebug.traits()`、`GameDebug.formation()`、`GameDebug.fusions()`。禁用角色不能通过调试入口解锁。
