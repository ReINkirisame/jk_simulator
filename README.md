# 女高模拟器

附中校园生活养成原型，当前版本 **0.6.0 · 特质与角色版**。

从高一九月玩到高三六月：高一探索兴趣，高二完成共同项目并试验生活方式，高三在有限精力中取舍，最后生成包含学业、关系、作品、传闻与状态的毕业画像。人物暂用原有称呼，完整人物线仍会继续扩写。

## 开始试玩

- 单文件版：下载“女高模拟器-v0.6.0.html”，用浏览器打开，无需联网。
- 源码版：完整解压项目，打开根目录 `index.html`；不要只移动这个文件。
- 选择后自动保存，也可导出 JSON。浏览器限制本地文件存储时，请使用导出、导入。
- 0.6.0 只接受同版本存档；旧版本游戏文件仍可独立运行，不会被覆盖。

## 当前规则

| 项目 | 规则 |
| --- | --- |
| 初始属性 | 学力、表达、体能、创造、外貌共用40点；每项0～20整数，允许极端偏科 |
| 能力成长 | 前四项每4经验升1点，上限30；每学期每项最多升3点；普通上课不再免费赠送学力 |
| 外貌 | 单独显示，普通练习不增长；永久变化预留在初始值±2内；用于出镜、选角等特殊场合，不直接换信任 |
| 家境与状态 | 家境不占属性点；零花钱、精力、压力独立记录 |
| 透支 | 精力不足仍行动时，缺口转成压力；压力溢出时继续损耗精力 |
| 判定 | 2d6加能力、状态、准备、特质和情境修正；结果显示原因 |
| 考试 | 月考一次策略，重要考试再加一次临场选择；策略前显示预计分数和状态代价 |
| 人物 | 关系与信任分开；八名人物拥有不同初遇，不再统一介绍后立即重复对话 |
| 生活习惯 | 高二设置学习、放学后、恢复三类方式；高三锁定其中两项，只留一次有限微调 |
| 校园传闻 | 由真实经历触发；回应进入论坛，并可能在后续人物对话中回收 |
| 毕业档案 | 汇总路线、能力、习惯、项目、关系、传闻、隐藏特质和遗憾，可下载 PNG |

## 特质与隐藏合成

开局候选池完全随机，不再为测试固定放入“癫佬”。隐藏特质也不会直接出现在候选池。

目前六个常规特质拥有成长型专属选项：癫佬、电波、社恐、吉他手、完美主义、冰山。专属选项会**替换一个允许替换的正常选项**，不会继承被替换选项的经验、信任或项目收益；安全回应和关键路线受保护。

同一常规特质每个自然月最多成长一次，4点到 Lv.2，8点到 Lv.3。失败仍会损伤关系、信任或状态。癫佬已改成明确的战斗脑气质，包括决斗、战斗爽、直尺选武器和把方案“砍断、切开、剁碎”；它不是无代价的抽象好感按钮。

角色型隐藏特质只能合成：

| 素材 | 隐藏特质 | 额外要求摘要 |
| --- | --- | --- |
| 癫佬 + 电波 | 古明地恋 | 合计12成长、各至少4、4人、3类场景、同一人接住两种表达；最早高二寒假 |
| 社恐 + 吉他手 | 后藤独 | 演奏/舞台、高压力使用、可信赖且接住两种表达的人；最早高二 |
| 完美主义 + 冰山 | 雪之下雪乃 | 学力16、直接帮助、真实关系摩擦；最早高二 |

满足条件后出现专属事件，玩家可以接受或暂缓。合成后来源特质仍留在档案，但其普通专属选项由隐藏特质接管；每项来源在一局中只能参加一次合成。隐藏特质不是纯升级，仍有资源成本和失败结果。

## 考试与状态改动

- 学力对总分的贡献改为每点约13分，取消按学年自动加分；学力20在正常状态下已进入约520分上下的区间。
- 分数保护范围改为180～735，不再把明显短板强行托到300分。
- 成绩单列出试卷基准、学力、考前准备、身心状态、特质、习惯、策略与临场。
- 精力与压力改为醒目的双条显示；精力30/10、压力70/90分别进入两级惩罚。
- 已声明的资源效果会在按钮上预览；考试策略还会显示预计成绩区间。

## 建议重点试玩

1. 用学力0、8、20开局对比月考，再查看成绩构成是否符合直觉。
2. 把精力压到30以下或压力推到70以上，确认按钮代价、判定修正和透支后果可见。
3. 选择一对合成素材，持续在不同人物和场景使用，观察升级与隐藏事件的节奏。
4. 比较普通帮助、安全倾听和特质替换选项，检查机会成本是否成立。
5. 留意八个初遇是否有各自记忆点，人物后续是否还显重复。
6. 做一次高二项目并调整生活习惯，再看高三锁定和毕业档案怎样回收。
7. 在结果页刷新或读档，检查能否回到同一页面；毕业后试一次 PNG 导出。

## 自动检查与打包

需要 Node.js，无第三方运行依赖：

```bash
npm test
npm run build
npm run test:standalone
```

当前测试包含34组规则边界和8条完整三年路线。构建会在项目外的 `release/` 目录输出单文件 HTML；源码无需构建即可运行。

可选真实浏览器脚本为 `tools/browser-check.js`，需要另行安装 Playwright 与 Chromium。它不属于 `npm test`，规则模拟通过不能代替桌面和手机视觉验收。

页面底部调试面板可跳月份，并分别补齐三条合成线的素材；使用后会标记为调试局，不覆盖正常存档。状态接口为 `GameDebug.getState()`、`GameDebug.traits()` 与 `GameDebug.fusions()`。
