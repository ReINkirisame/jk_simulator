# 女高模拟器

附中校园生活养成原型，当前版本 **0.5.0 · 三年基础版**。

从高一九月玩到高三六月：高一探索兴趣，高二完成共同项目，高三安排有限的精力，最后生成包含学业、关系、作品与状态的毕业画像。人物暂用原有称呼；完整个人线、群像冲突和更多特殊事件仍待扩写。

## 开始试玩

- 单文件版：下载“女高模拟器-v0.5.0.html”，用浏览器打开，无需联网。
- 源码版：完整解压项目，打开根目录的 `index.html`。不要只移动这个文件。
- 选择后自动保存；可导出 JSON 备份。浏览器限制本地文件存储时，请使用导出、导入。
- 0.5.0 的属性和流程已重构，只接受同版本存档；旧版本游戏文件仍可独立运行。

## 这一版的规则

| 项目 | 当前规则 |
| --- | --- |
| 初始属性 | 学力、表达、体能、创造、外貌共用40点；每项0～20整数，允许偏科 |
| 能力成长 | 前四项每4经验升1点，上限30；每学期每项最多升3点 |
| 外貌 | 单独显示，不通过普通练习增长；预留相对初始值±2的永久变化边界，当前事件没有永久改貌 |
| 家境 | 不占点数，单独选择；影响每月零花钱，付费事件保留免费路径 |
| 即时状态 | 零花钱、精力、压力，与能力分开 |
| 人物关系 | 关系和信任分别记录；外貌不直接产生信任 |
| 判定 | 2d6加能力、状态、准备等修正；结果页显示原因 |
| 考试 | 月考一次策略；重要考试多一次临场选择；不逐科重复决策 |

癫佬选项现在会**替换一个正常的主动选项**，不继承它的经验、信任等奖励。安全回应和关键路线选择受保护。失败可能损伤关系与信任，并留下后续尴尬。

成长每个自然月最多计一次，4点到Lv.2，8点到Lv.3。古明地恋还要求12点成长、4名人物、3类场景，并且最早到**高二寒假1月**才可能触发专属进化事件。满足条件不等于自动获得；进化后仍有代价和失败可能。

## 建议重点试玩

1. 比较均衡、双项极端和外貌型开局，看看优势和短板是否能感知。
2. 在同一随机种子下改变选择，比较正常帮助、认真倾听和癫佬的后果。
3. 留意高一照片、花灯、学生会经历怎样在之后被提起和用于判定。
4. 做一次高二项目，再看高三安排怎样影响能力、状态和毕业画像。
5. 在选择结果页刷新、读档，检查能否回到原来的页面。

本版固定将“癫佬”放入10个候选特质，方便测试。普通玩局不保证进化：出现时间取决于实际选择和前置条件。

## 自动检查与打包

需要 Node.js，无第三方测试依赖：

```bash
npm test
npm run build
```

测试包含规则边界和6条完整三年路线。构建会在项目外的 `release/` 目录输出单文件 HTML；源码本身无需构建即可运行。也可指定输出路径：

```bash
node tools/build-standalone.js /你的路径/游戏.html
```

真实浏览器脚本为 `tools/browser-check.js`，需要另行安装 Playwright 和 Chromium，先启动本地静态服务器，再传入页面地址。它未包含在 `npm test` 中。

页面底部有折叠调试面板，可跳月份和补齐进化前置；使用后变为调试局，不覆盖正常存档。读取状态用 `GameDebug.getState()`。
