# 女高模拟器

这是“附中女高模拟器”的可维护项目版。目前内容覆盖高一入学至高一暑假，保留了原单文件草稿的特质、属性、社团、路线、考试、NPC 与随机事件。

当前版本：`0.4.0`

## 0.4 最值得试玩的内容

1. 开局候选池中会固定出现一次“癫佬”，选中它和另外两个特质。
2. 在人物互动中选择紫色 `【癫佬 Lv.x】` 选项；普通阶段可能真正降低关系，严重失败还会在下次见面留下后续。
3. 连续使用四次后解锁“古明地恋”，再比较判定修正和 NPC 反应的变化。
4. 用不同选择各玩一次九、十月，查看学生会延迟结果、NPC 假期互动、月考成绩构成和十月底人物小结。
5. 继续玩到十二月，确认十月选择的花灯样式会在展示事件里再次出现。

游戏采用半透明 2d6 判定：玩家不需要管理骰子，但结算会说明属性、特质、前置准备和 NPC 适应度怎样影响结果。

## 最快的试玩方法

1. 下载并解压整个项目。
2. 双击项目最外层的 `index.html`。
3. 浏览器会直接打开游戏，不需要安装依赖，也不需要联网。

如果页面只有文字但按钮不能工作，请确认解压后目录结构没有被改变，并查看“遇到问题怎么办”。

## 我想修改内容，应该去哪？

| 想修改的东西 | 文件 |
| --- | --- |
| 页面颜色、按钮、排版 | `styles.css` |
| 开局特质 | `src/data/traits.js` |
| 特质专属选项、解锁条件 | `src/data/trait-choices.js` |
| 特质触发概率、关系结算 | `src/core/trait-system.js` |
| 骰点、难度和判定等级 | `src/core/check-system.js` |
| NPC 的称呼和简介 | `src/data/npcs.js` |
| 高一固定事件 | `src/data/events-year1.js`、`events-year2.js` |
| 路线事件 | `src/data/routes.js` |
| 随机事件、特质专属事件 | `src/data/random-events.js` |
| 事件如何推进、考试与假期流程 | `src/core/game.js` |
| 按钮与结果如何显示 | `src/core/ui.js` |
| 开局数据结构 | `src/core/state.js` |

第一次修改建议只改一个文件、一个小目标。改完后马上试玩，不要一次要求 AI 同时增加人物、恋爱、存档和高二。

## 自动检查（可选）

电脑安装了 Node.js 后，可在项目目录运行：

```bash
npm test
```

它会模拟“总选第一个”“交替选择”和“遇到特质选项就选择”三种完整流程，并额外验证固定骰点、癫佬负关系、延迟后果、九十月持久记录、考试压缩和十月底小结。它不能证明剧情一定好玩，但能发现常见的括号错误、文件漏加载、假持久化和流程中断。

## 上传和合作

请阅读 [GitHub 新手操作指南](docs/GITHUB_GUIDE.md)。最重要的规则只有三条：

1. `main` 永远保存当前能玩的版本。
2. 每个任务先创建自己的分支，再修改。
3. 合并前至少完整试玩一次；能运行 Node.js 时再执行 `npm test`。

## 当前版本做了什么

- 将原先一个约 110 KB 的 HTML 拆成页面、样式、数据和流程文件。
- 保留原始版本于 `legacy/`，便于核对。
- 合并了原文件末尾通过重复定义函数形成的补丁结构。
- 修复“很多选项已经写了结果文字，但点击后不显示”的通用界面问题。
- 增加启动时的数据检查和无需第三方依赖的流程测试。
- 建立可复用的特质专属选项注入层，并完整做出“癫佬 → 古明地恋”样板。
- 加入特质成长、隐藏特质、NPC 适应度、防连续重复和触发保底。
- 建立统一 2d6 判定，让普通癫佬具有真实风险并能留下延迟后果。
- 重做九、十月固定事件，加入持久选择记录、延迟回收和阶段人物小结。
- 把月考压缩为一次策略选择，把重要考试压缩为两次不同层级的决定。
- 没有新增恋爱、存档、高二、高三或多结局系统。

## 遇到问题怎么办

先依次检查：

1. `index.html` 是否仍在项目最外层；
2. `src` 文件夹是否和 `index.html` 放在一起；
3. 是否只上传了 `index.html`，漏传其他文件；
4. 浏览器按 `F12` 后，Console 中是否出现红色错误；
5. GitHub Desktop 的 “Changes” 中是否有未提交文件；
6. 执行 `npm test` 时出现的第一条错误是什么。

报告问题时请附上：做了什么、预期发生什么、实际发生什么、控制台第一条红色错误，以及对应分支名称。
