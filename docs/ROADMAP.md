# 开发路线（0.5.1更新）

## 已有基础

- 0.2：单文件拆分、原稿留存、结果显示与流程检查。
- 0.3：癫佬专属选项与古明地恋的早期样板。
- 0.4：2d6、负面关系、九十月固定事件、延迟后果与考试压缩。
- 0.5：五属性40点、成长/资源分离、选项替换、跨学期进化、三年日历、项目、关系与信任、毕业画像、可恢复到当前页的存档。
- 0.5.1：高二习惯试错、高三锁定、校园论坛、条件传闻、跨事件回收和可下载毕业档案。

历史版本曾采用四次发癫进化等规则，已由0.5替代，不再作为扩写依据。

## 0.5.1之后先验收什么

- [ ] 极端开局是否有明显但能补救的短板，均衡开局是否仍有价值。
- [ ] 外貌目前只影响少量专项场合，投入的机会成本是否合适。
- [ ] 癫佬替换掉正常帮助后，玩家是否确实感到得失。
- [ ] 自然游玩时的进化分布是否集中在高二末/高三初；不同种子的长期选择需继续观察。
- [ ] 重要考试的两次决定是否真的不同，结果页是否仍显冗长。
- [ ] 高一到高三的文本密度与重复人物场景是否影响节奏。
- [ ] 手机浏览器和不同本地文件打开方式的实际体验。
- [ ] 三类习惯的月度收益与更换代价是否让玩家感到差异，但没有压过具体事件。
- [ ] 高二两次复盘、高三一次微调是否足够；锁定两项是否让取舍可感知而不致于后悔整局。
- [ ] 一局自然出现1～5条传闻是否合适，条件和文本是否真的像别人对经历的误读。
- [ ] 论坛两条/月的背景密度是否太高；小屏侧栏是否影响阅读。
- [ ] PNG毕业档案在常用桌面与手机浏览器中的下载、中文字体和长名字排版。

## 下一轮内容扩充

1. 确定核心人物名字、年级、目标与关系网，保留原称呼到新名字的映射。
2. 把每人每学年的一个样板扩为连续事件链，加入与玩家无关的行动、冲突和后续。
3. 将关系好坏、信任、友情与恋爱意图写进更具体的事件，完善毕业关系的前置。
4. 为外貌增加少量明确场合和额外曝光的负担，避免变成通用好感属性。
5. 深化高二三类项目的独有内容，减少共享流程的同质感。
6. 高三让早期选择形成具体可惜、补救与告别，增加对未完成项目和疏远人物的回收。
7. 给传闻增加少量人物专属后续和互相矛盾的版本，不把数量本身当作内容深度。

这些是待设计项，不表示已经实现。

## 后续机制

- 评估家境收入、付费机会和免费替代的平衡；当前钱的用途仍偏少。
- 给第二种特质做完整的替换与成长样板，再泛化里程碑结构。
- 将旧高一数组事件逐步迁移为对象事件，避免效果与文本分散维护。
- 明确跨版本存档迁移策略；当前仅支持精确版本重放。
- 根据试玩记录决定是否压缩普通结果页，不机械删除所有反馈。
- 评估跨周目“校园传闻图鉴”，但在单局内容足够丰富以前不做全服/伪全服系统。
- 如需分享月度记录，先设计隐私、安全与信息密度；0.5.1只提供毕业档案，不自动上传任何数据。

## 发布纪律

每次新增机制都同时检查真实收益、代价、后续读取和可解释反馈。先修已证实的问题，再扩大内容量。保留可玩基线、稳定事件ID和版本说明。
