# 开发路线（0.6.0更新）

## 已有基础

- 0.2：拆分单文件、原稿留存、结果显示与流程检查。
- 0.3：癫佬选项与古明地恋早期样板。
- 0.4：2d6、负面关系、延迟后果与考试压缩。
- 0.5.0：五属性、成长/资源分离、三年日历、项目、关系、毕业画像与存档。
- 0.5.1：高二习惯试错、高三锁定、校园论坛、条件传闻与毕业档案图片。
- 0.6.0：六个常规成长特质、三条角色合成线、癫佬气质重写、考试/状态重标与八个独立人物初遇。

四次发癫直接进化等历史规则已废弃。0.6.0中“进化”统一称为“双来源隐藏合成”。

## 0.6.0优先试玩数据

- [ ] 学力0、8、20、30的考试分布是否落在预期区间，预览是否会误导玩家。
- [ ] 去掉每月免费学力后，均衡与偏科角色到毕业时是否仍有明显差异。
- [ ] 精力30/10与压力70/90的警告、判定变化和溢出后果是否足够可见。
- [ ] 按钮上的资源预览是否覆盖了最常见的高成本行为，是否与结算一致。
- [ ] 癫佬是否稳定呈现“战斗脑/决斗”，而不是重新滑回泛用抽象梗。
- [ ] 古明地恋自然触发是否大多在高二寒假以后，既不会四次速成，也不会几乎无法出现。
- [ ] 后藤独的高压力舞台条件、雪之下雪乃的摩擦条件是否可理解、可自然满足。
- [ ] 隐藏特质接管来源后，玩家是否能感到变化，同时仍理解两个来源保留在档案中的意义。
- [ ] 八个初遇是否有独立记忆点；节省一次重复对话后，人物关系成长是否仍足够。
- [ ] 重要考试的两次选择和固定事件的结果页是否仍显繁琐。
- [ ] 桌面、手机、本地文件打开、JSON导入导出与PNG档案的真实浏览器表现。

## 下一轮内容扩充

1. 确定核心人物正式名字、年级、目标与关系网，保留旧称呼映射。
2. 把每人每学年的一个样板扩为连续事件链，加入人物之间的关系与不依附玩家的行动。
3. 增加常规成长特质，使更多开局组合拥有可玩的表达，而不是只有六项进入新系统。
4. 扩展角色型隐藏合成；每个新角色必须有两项合理来源、独特行为门槛、专属事件、失败代价和毕业回收。
5. 深化三类高二项目的独有事件，减少共享模板。
6. 为外貌增加少量真正适用的特殊场合与曝光负担，保持它不是通用好感属性。
7. 增加人物专属传闻、冲突版本和跨人物回收，不把论坛数量当作内容深度。
8. 在单局内容更丰富后，再评估月度分享卡与跨周目校园传闻图鉴；不制作伪全服数据。

## 技术债与后续机制

- 将旧高一数组事件逐步迁移为对象事件，使效果、成本预览和后续影响集中维护。
- 继续补全动态 `run` 行为的成本预览，避免文字与实际结算分散。
- 明确跨版本存档迁移策略；当前只支持精确版本重放。
- 根据试玩记录决定是否压缩普通结果页，不机械删除视觉小说式反馈。
- 评估钱的长期用途与免费替代平衡，当前零花钱仍比精力、压力更少参与核心循环。
- 若做截图分享，先明确隐私、信息密度与字体兼容；0.6.0只在本地生成毕业档案，不上传数据。

## 发布纪律

每次新增机制都同时检查真实收益、代价、后续读取、成本预览和可解释反馈。保留稳定事件ID与可玩基线；改变随机调用、状态结构或重放路径时必须升级版本并重新跑源码/单文件一致性检查。
