# 开发路线（0.6.1更新）

## 已有基础

- 0.2～0.4：拆分原稿、特质替换、统一2d6、负面后果与考试压缩。
- 0.5.0：五属性、资源分离、三年日历、项目、关系、毕业画像与存档。
- 0.5.1：高二习惯试错、高三锁定、论坛传闻与毕业档案图片。
- 0.6.0：六项常规成长、角色合成框架、癫佬重写、考试/状态重标与八个独立初遇。
- 0.6.1：60项普通特质分类和基础作用、六项跨领域专属行动与后天形成；隐藏角色仅保留古明地恋，其他样板暂停。

“四次发癫直接进化”已废弃。当前古明地恋要求两个来源各至少4个月成长、月份并集至少12个月与人物/场景条件，最早高二寒假。后天形成的4个月准备期不折算为特质成长。

## 0.6.1优先试玩

- [ ] 60项特质的作用说明与真实领域、判定明细、月间恢复是否一致。
- [ ] 正向普通特质+2封顶后，组合仍有区别，而非只堆相同加成。
- [ ] 生活特质的恢复和额外成本、非酋的固定逆风与有限复盘是否能被理解。
- [ ] 普通练习入口是否自然：取代相处/假期有可感知代价，又不成为每月强制任务。
- [ ] 只持有一个素材能否后天形成另一个；4个月门槛、最早高一下与暂缓3个月是否合适。
- [ ] 后天获得从0XP开始、同月成长去重和最多新增2项是否容易理解。
- [ ] 六项专属行动在学习、项目、创作、音乐等领域是否产生真实差异。
- [ ] 古明地恋是否能在高二寒假后自然出现，是否仍满足4人、3场景与共同成功对象。
- [ ] 合成后社交表达确有变化，普通活动来源做法与基础作用继续可用。
- [ ] 考试分布、精力30/10和压力70/90反馈、人物重复感与结果页点击节奏。
- [ ] 桌面、手机、本地文件、JSON存档与PNG导出的真人浏览器验收。

## 后续内容

1. 继续扩写八名NPC的跨月份事件链、各自目标与相互关系；正式姓名由作者确定，暂沿用旧称呼。
2. 按试玩优先增加有区别的普通特质事件，不把“60项基础作用”包装成“60条完整剧情”。
3. 深化三类高二项目的独有内容，减少共享模板，增加早期选择的真实回收。
4. 为外貌增加少量适用场合和被关注的负担，保持不是通用好感属性。
5. 丰富传闻的冲突版本与跨人物回收，不把论坛条数当作内容深度。
6. 其他隐藏角色暂不开发。日后若群友本人愿意提供具体行为、自述或趣事，并确认可采用范围，再讨论角色、素材和玩法；不把头像视为扮演或强行推断性格。
7. 单局内容充分后再评估月度分享卡、跨周目图鉴；不制作伪全服数据。

## 技术债与发布纪律

- 逐步将旧高一数组事件迁移为对象格式，统一成本预览、领域、明确形成证据和延迟效果。
- 验证预测与真实结算分离，避免查看成绩预览获得失败经验或重复支付代价。
- 当前仅支持精确版本重放；0.6.1使用独立键，旧存档用旧版本打开，不声称自动迁移。
- 控制强制菜单和低信息点击，同时保留有意义的视觉小说结果反馈。
- 每次发布执行 `npm test`、单文件构建与源码/单文件一致性检查；真实浏览器测试单独记录。
- 任何随机调用、事件ID、状态或效果改变均升级版本。保留历史发布说明，不追改旧版事实。

本版范围与实际验证结果见 [RELEASE_0.6.1.md](RELEASE_0.6.1.md)。
