# 游戏设计共识

这份文件记录目前已经确认的方向。以后无论由人还是 AI 增加功能，都应先核对这些原则。

## 一句话定位

玩家在一所取材于真实附中的高中里度过三年，通过性格、兴趣、选择、成功和失败，最终养出一个有鲜明经历的女高中生。

## 已确认事项

1. 面向不了解原学校的陌生玩家，而不只是校友内部作品。
2. 玩家重走的是创作者熟悉的附中生活；真实细节作为世界质感，而非理解门槛。
3. 人际内容包含友情、恋爱与群像。
4. 基调允许大量二次元梗、怪事件和抽象喜剧。
5. 最终范围是完整高中三年。
6. 游戏需要养成、成功与失败、多种路线和多结局。
7. NPC 不影射现实中的具体同学，可以完全虚构。
8. 最重要的玩家感受是：“我养出了一个很有意思的女高中生。”

## 设计判断标准

增加新机制或事件前，至少回答一个问题：它怎样让玩家养出的女孩更具体、更不同？

仅仅增加点击次数、同义选项或只出现一次的人物，不算有效成长。

## 三年结构建议

- 高一：探索。认识人、试社团、发现兴趣，角色还没有定型。
- 高二：分化。路线确定，朋友圈形成，友情和恋爱产生冲突。
- 高三：取舍。时间和压力增加，玩家决定保留什么、放弃什么，并完成告别。

## 叙事原则

- 内部梗不能成为理解情节的前提。
- 梗可以负责表面语气，人物动机和后果仍需成立。
- 失败应产生后续故事，而不只是拒绝玩家进入内容。
- 核心 NPC 应跨月份、跨学年重复出现，并拥有不依附玩家的目标。
- 结局应综合学业、关系、兴趣、身心状态、校园传说和遗憾，而不只看总分。

## 当前近期目标

先把高一九月和十月做成纵向样板：属性会改变、特质会影响选项、三名 NPC 会重复出现、选择会产生延迟后果，并能够形成十月底人物小结。

在纵向样板通过试玩以前，不批量扩写高二和高三。
