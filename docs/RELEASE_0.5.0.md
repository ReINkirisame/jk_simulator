# 女高模拟器 0.5.0 · 三年基础版

这次把属性、代价、成长和存档接进了完整的三年流程。它可以从入学玩到毕业，人物长线和事件密度仍是下一轮扩充的重点。

## 直接试玩

打开“女高模拟器-v0.5.0.html”即可离线运行。源码包解压后打开根目录 index.html，效果相同。界面会自动保存；建议用“导出存档”保留一份 JSON，尤其是在浏览器限制本地文件存储时。

## 回应这次提出的问题

| 问题 | 已实现的改动 |
| --- | --- |
| 属性有没有用 | 五项分别接入考试、交流、恢复、创作、出镜；结果显示判定和实际变化 |
| 保留外貌 | 开局与状态栏单列外貌；普通训练不改变它，当月仪容独立计算 |
| 点数最低应到0 | 五项共40点，每项0～20；校验不把超限输入偷偷改回合法值 |
| 家境怎样处理 | 独立选择背景，影响每月收入；必要学习与主线保留免费路径 |
| 癫佬像白拿的正收益 | 紫色选项替换一个正常主动选项，不继承原收益；失败损伤关系与信任 |
| 四次就进化太快 | 每月最多成长一次，4点仅到Lv.2，8点到Lv.3；进化另有四重前置和专属事件 |
| 进化最早时间 | 高二寒假1月起，仍需12次月度成长、4名人物和3类场景 |
| 固定事件没影响 | 补充能力经验、资源、关系和项目效果；照片、花灯、项目经历等被后续读取 |
| 考试选择繁琐 | 月考一次策略；重要考试一次策略加一次临场决定，再显示成绩 |
| 要不要随机数 | 使用带种子的2d6；能力与准备影响结果，读档保留随机序列 |

学力、表达、体能、创造每4经验提升1点，每学期每项最多提升3点，上限30。外貌预留初始值±2的永久变化边界，本版暂未放入永久改貌事件。

## 三年里新增了什么

- 高一保留原有内容，增加班级照片、明确的能力训练和关系后果。
- 高二可选校园留声册、校园问题研究、放学后运动会，经历样品、分工、预算、展示、交付。
- 高三选择优先学业、创作、身心或关系，月度状态与能力随之变化，寒假和最后阶段可调整。
- 八名旧称呼人物有分学年的目标与互动样板，关系与信任分开；毕业可选择继续友情、写信或满足前置后的表白。
- 毕业画像同时读取学业、成长、项目、关系、校园传说、身心状态和重要记忆。
- 增加当前页自动存档、JSON导入导出、随机种子，以及不会覆盖正常存档的调试面板。

## 当前边界与下一轮重点

1. 人物沿用原称呼；每学年仍主要是一个互动样板，可能重复。完整个人线和群像关系还需创作。
2. 外貌有专项用途，但内容数量较少；40点预算、外貌投入和家庭收入仍需要实际试玩校准。
3. 旧事件已补效果，部分旗标仍主要用于记忆或阶段总结，不是每一个都具有专属后续剧情。
4. 高二三类项目共享不少流程，下一步应增加各自独有的障碍、人物冲突和结果。
5. 存档只支持本版本。流程仍含旧闭包，当前用操作重放恢复；未来修改事件或随机调用需升级版本并处理兼容。
6. 真实浏览器与手机体验仍待实测；接下来优先收集实际选择和重复感，不继续堆同义选项。
