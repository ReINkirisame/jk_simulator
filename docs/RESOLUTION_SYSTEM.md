# 随机判定与考试系统

## 为什么使用 2d6

两个六面骰的结果集中在 6～8，极端的 2 和 12 很少出现。它适合校园日常：能力和准备通常决定大方向，运气可以造成意外，但不会像单颗大骰子那样频繁把结果推到极端。

## 基本公式

```text
判定值 = 2d6 + 属性修正 + 特质修正 + 前置准备 + 情境修正
```

判定值与难度比较后分为：

- 大失败：差值不高于 -3；
- 小失败：差值为 -2 或 -1；
- 普通成功：达到难度，但没有高出 3；
- 特别成功：高出难度至少 3。

属性不会按原始数值直接加入骰点，而会先压缩到 `-2` 至 `+3`，防止开局高属性完全淹没随机，也防止低属性永远没有故事。

## 哪些事情判定，哪些不判定

直接由玩家决定：

- 加入哪个社团；
- 选择和谁见面；
- 是否报名、是否继续兴趣；
- 文理意向和长期投入方向。

适合使用判定：

- 报名后的选拔表现；
- 考场发挥；
- 舞台、竞赛等有风险的公开表现；
- “癫佬”选项造成的 NPC 反应。

随机结果不得无说明地删除重要路线。失败应留下试训、补救、尴尬、绕路或其他后续内容。

## 考试交互

- 月考：一次总体策略选择，随后直接出现成绩单。
- 期中、期末、开学考试：一次总体策略，加一次临场抉择。
- 高考等最终高潮可以以后单独设计，但不应简单恢复五科重复点击。

成绩由学业基础、健康状态、特质、策略和一次判定共同形成。结果页会显示构成，方便试玩阶段判断数值是否合理。

## 开发规则

- 内容代码使用 `gameRandom()`、`randomInt()` 或 `randomItem()`，不要直接增加 `Math.random()`。
- 自动测试可向 `resolveCheck()` 传入 `dice:[1,1]` 等固定骰点。
- 新判定至少测试一个失败和一个成功结果。
- 如果玩家无法在选择前理解风险，或结算后无法理解原因，就不算“半透明判定”。
