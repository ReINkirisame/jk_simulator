# 随机、属性、状态与考试（0.6.1）

本版沿用0.6.0的属性和考试分数公式。新增的普通特质作用统一由领域判定读取：正向基础修正合计最多+2，负向另算；预览不抽骰、不支付额外费用，也不发放失败复盘经验。实际考试先固定本场分数，再结算特质费用和非酋复盘，避免结算中升级反过来抬高本场成绩。基础作用、成长与后天形成详见 [TRAIT_SYSTEM.md](TRAIT_SYSTEM.md)。

## 随机负责什么

玩家决定意图：加入哪个社团、做什么项目、和谁见面、是否使用高风险特质。判定负责不确定表现：选拔、考试发挥、公开活动和人物对特殊表达的反应。

游戏使用2d6。每局有种子，相同初始配置与操作顺序得到相同结果；读档通过确定性重放恢复随机序列，不能靠刷新结果页重掷。

判定值 = 2d6 + 属性修正 + 状态/准备/特质/情境修正。

| 属性值 | 修正 |
| --- | ---: |
| 0～3 | -2 |
| 4～7 | -1 |
| 8～11 | 0 |
| 12～15 | +1 |
| 16～19 | +2 |
| 20～24 | +3 |
| 25～30 | +4 |

与难度之差≤-3为大失败，-2～-1为小失败，0～2为普通成功，≥3为特别成功。结算页显示骰点、修正、合计与难度。

## 属性与成长

| 属性 | 已接入用途 |
| --- | --- |
| 学力 | 考试、竞赛、研究、校对与部分人物帮助 |
| 表达 | 主动交流、协商、讲解、表演与部分特质表达 |
| 体能 | 运动、每月恢复、考试身心状态 |
| 创造 | 美术、构图、作品、音乐与跳跃思路 |
| 外貌 | 出镜、海报、选角与第一印象旗标；不增加信任 |

前四项每4经验升1点，每学期每项最多升3点，最终上限30。普通课程月份只消耗日常精力，不再无条件赠送学力经验；学习习惯、复习、考试回顾、路线和事件才产生学习成长。外貌没有普通训练经验，永久修改限在初始值±2；当月仪容另记。

## 精力与压力

界面始终显示两条醒目状态条。普通能力判定读取以下阈值：

| 状态 | 判定影响 |
| --- | ---: |
| 精力≥75 | +1 |
| 精力<30 | -1 |
| 精力<10 | 再-1 |
| 压力≥70 | -1 |
| 压力≥90 | 再-1 |

精力不会因为到0而让后续成本凭空消失。若精力2仍执行精力-12的行动，实际精力归0，缺少的10点行动量按75%向上取整转成压力+8。压力超过100时，溢出量的一半向上取整转成额外精力损失。

这两个溢出规则防止“已经归零，所以再怎么熬都免费”。事件仍应保留休息、安全回应或缩小规模的替代方案。

## 考试结构

- 月考：选择一次总体策略，直接出成绩。
- 期中、期末、开学与毕业考试：总体策略 + 一次临场决定，再出成绩。
- 不逐科要求五次相似选择。
- 策略按钮显示当前预计区间以及精力、压力变化。

总分公式由以下部分相加并限制在180～735：

1. 试卷基准：当前为250～280，后期试卷略高；
2. 学力贡献：学力 × 13；
3. 考前准备：每点准备 +3；
4. 体能、当前精力与压力；
5. 特质和稳定学习习惯；
6. 策略、临场选择与一次2d6发挥等级。

取消旧版按学年自动加分。固定中位骰、正常状态下的设计目标约为：

| 学力 | 常见总分感受 |
| ---: | --- |
| 0 | 约200～330，明显短板但不阻断主线 |
| 8 | 约360～450 |
| 20 | 约520～590 |
| 30 | 后期重要考试约670～730 |

具体分数仍受试卷、状态、准备、习惯和骰点影响。它是游戏数值，不是现实升学预测。

成绩单固定列出：试卷基准、当时学力及贡献、考前准备、身心状态、特质、习惯、策略与临场。考试结束后提供1点学力经验，表示复盘，而不是每月免费增长。

## 失败原则

- 一次坏骰不能无说明地永久关闭主线。
- 失败可以产生尴尬、关系下降、缩小项目、补救路径和后续记忆。
- 关系与信任允许为负，不能把所有失败改写为等额奖励。
- 外貌机会、项目结果、早期物件和固定选择应在后续被读取。

内容只使用 `gameRandom`、`randomInt`、`randomItem`。固定骰只用于自动测试或调试。新增判定必须覆盖失败与成功，并在按钮或场景文字中让玩家看见主要风险。
