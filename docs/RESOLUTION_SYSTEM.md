# 随机、属性与考试（0.5.1）

## 随机负责哪些事

玩家决定意图：选社团、选项目、和谁交往、是否告白、保留哪种生活。判定负责不确定的表现与反应：选拔、考试、公开活动、癫佬社交等。

使用2d6，两个六面骰之和集中在中间。每局有种子，相同初始配置和操作顺序得到相同结果；读档保留随机序列，不靠刷新结果页重新掷骰。

公式：判定值 = 2d6 + 属性修正 + 状态/准备/特质/情境修正。

| 属性值 | 修正 |
| --- | ---: |
| 0～3 | -2 |
| 4～7 | -1 |
| 8～11 | 0 |
| 12～15 | +1 |
| 16～19 | +2 |
| 20～24 | +3 |
| 25～30 | +4 |

与难度之差≤-3为大失败，-2～-1为小失败，0～2为普通成功，≥3为特别成功。结果页显示骰点、各项修正、合计与难度。

## 五项属性各自做什么

| 属性 | 已接入用途 |
| --- | --- |
| 学力 | 考试基础与判定、竞赛、研究项目、部分人物帮助 |
| 表达 | 主动交流、协商分工、讲解与公开表演 |
| 体能 | 运动项目、每月恢复、考试状态与部分人物帮助 |
| 创造 | 美术路线、海报/构图、作品项目与创作 |
| 外貌 | 出镜与海报判定、第一印象相关旗标；不增加信任 |

学力、表达、体能、创造通过经验成长：4经验升1点，每学期每项最多升3点，最终上限30。达到学期上限后不囤积额外经验。外貌没有训练经验，当前事件不永久改变它；永久修改接口限在初始值±2内，当月仪容修正单独记录。

常规活动判定会读取精力与压力：精力≥75时+1，精力<25时-1，压力≥70时-1。外貌判定只读取适用的仪容与场合，不借用这些状态。

这些规则是当前平衡起点。外貌专项内容比可训练能力少，不能据此宣称五种投入已经等价。

## 考试与点击

- 月考、模拟：一次总体策略选择，直接出成绩，再点一次继续离开成绩单。
- 期中、期末、开学与毕业考试：一次策略，再一次临场决定，最后出成绩。
- 没有五科各选一次的重复流程。

成绩读取学力基础、学年进度、体能与当前状态、特质、策略、准备、稳定的学习习惯及一次受限随机表现。基础复盘直接改善分数兑现；限时训练改善考场判定；错因补缺对低学力构筑帮助更大。习惯未维持两个月时只显示“仍在磨合”，不提供考试加成。

结果页列出构成。当前总分按750展示，并限在300～680之间；这是原型的数值保护范围，不代表真实升学预测。

能力0表示短板。免费学习、休息和安全回应保证能继续生活，低能力角色不会因一次失败失去主线。长期选择仍影响实际分数、项目规模、关系与状态。

## 后果与失败

- 一次失败不能无说明地永久关闭重要路径。
- 外貌不佳或海报试拍失败仍有物件海报、设计、联系等办法。
- 项目失败仍留下少量进展和经验，但规模与完成结果可能不同。
- 关系与信任可为负数；不能把所有失败写成另一种等额奖励。
- 固定事件的差异要被后续使用，例如照片邀约、项目准备、花灯回忆、毕业画像。

## 开发约定

内容只使用 gameRandom、randomInt、randomItem。固定骰点仅用于测试或标记为调试局的检查。新增判定应覆盖一个真正的失败分支和一个成功分支；新资源消耗应保留合理退出或替代路径。
