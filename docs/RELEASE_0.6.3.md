# 女高模拟器 0.6.3 · 特质日常与回响

本版完成本轮讨论的四项改进，以及此前暂缓的“每学年特质日常”和“旧选择后续回响”。沿用现有手记式界面和三年结构；60项普通特质、六条成长线，隐藏角色仍只有古明地恋。

## 1. 普通特质有实际入口

- 跨年群聊、每年假期的可选近况帖子使用真正的“线上表达”判定。有成功和失败的资源/经验后果，话痨、社恐等线上特质可以实际发挥。
- 社团活动周的主动参与使用社团领域与活动本身的领域判定。成功获得相关能力经验2，失败1，均支付精力；后台/安全选项仍保留。
- 不把休息、普通浏览或每句聊天都改成掷骰任务。假期新行动仍是一次主要安排，沿用原结果页。

## 2. 修正+2封顶后的错误扣费

正向普通特质合计仍最多+2。先计入无新增消耗的来源，再按单位修正的新增资源消耗排列，同分按持有顺序。明细列出真正贡献的名字与实际数值。

例如“现充+1、开朗+1”已经达到上限，同场的社交悍匪不再被记作加成来源，也不收本月首次消耗。若只剩现充与社交悍匪，后者贡献剩余的+1，仍支付一次完整月费。已付月费的来源当月再次发挥不收费。

负向特质照常计算；专属行动自己的精力、压力与失败代价不会因为普通加成封顶而免除。预测、实际结算和按钮成本提示共用同一分配规则。

## 4. 升级后能看见新的做法

- 升级直接在原结果页显示“Lv.1 → Lv.2”等提示。
- 下一个有对应等级新模板、满足人物/活动条件且允许替换的场景，优先展示一次新选项，不再被普通抽取概率压住。玩家可以不选它。
- 考试、安全回应、重要路线及不适合音乐的场景仍受保护；不合适就继续等待。再次升级后，新的等级提示接替未展示的旧等级提示。
- 增加电波二级活动模板、六项三级活动模板，具有各自的表达与资源取舍。三级普通活动专属判定沿用额外+1；合成后保留的来源活动也能展示三级做法。
- 展示新选项不会赠送成长经验；仍需跨4/8个自然月真实使用才能达到二/三级。

## 5. 每学年一次特质日常

每年11月，从已经持有的普通特质中优先选择未经历过的一个；同次数按持有顺序。每局正常三年共三场，高一替换一次普通随机互动，高二、高三替换当月普通人物互动。生日和固定事件照常。

六项成长特质有专用日常文字，其他普通特质按活动领域组织。每场有投入与休息的取舍，记录真实选择与后果；休息不会丢失特质，日常也不会自动增加成长或形成证据。不是每项特质每年各弹一次，也不是180条独立剧情。

## 6. 三条旧选择的后续回响

| 早期决定 | 后续场合 | 实际影响 |
| --- | --- | --- |
| 高一学生会报名/旁听与面试结果 | 同年11月才俊杯 | 舞台与后台占用同一段时间；后台成功可补入正式名单，失败保留志愿者经历；正式干事仍能影响后续项目分工 |
| 教师节听取老师建议，或维持初中朋友联系 | 高二3月项目返工 | 建议路线限定返工范围：本次判定+1、精力消耗降到5；旧友路线获得一次线上试用，按结果产生不同进展 |
| 入学时独自探索，或跟同学同行 | 高三3月状态调整 | 安静连廊更侧重减压；沿旧路同行同时恢复状态和维系当年的同伴，读取确实记录的那个人 |

后续在既有事件位置出现。必须有真实前置选择，只有实际使用相关后续做法才结算并记入经历；没有额外的每月回响确认页。
