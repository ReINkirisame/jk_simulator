# 女高模拟器 0.6.0 · 特质与角色版

## 运行与存档

打开“女高模拟器-v0.6.0.html”即可离线运行。源码包解压后打开根目录 `index.html`，效果相同。

0.6.0使用独立本地存档键，只读取同版本存档。0.5.1及更早文件不会被覆盖，仍可分别运行；本版不提供旧档迁移，因为特质状态、随机池、人物初遇和考试流程都改变了确定性重放路径。

## 本版主题

本版把旧版“一个成长特质 + 一条进化线”的样板扩成两层系统：

- 常规特质：从开局随机获得，可按月成长到 Lv.3。
- 角色型隐藏特质：不进开局池，由两项常规特质、长期行为和专属事件合成。

首批接入六项常规成长特质与三条合成线：

| 常规来源 | 隐藏结果 | 核心门槛 |
| --- | --- | --- |
| 癫佬 + 电波 | 古明地恋 | 合计12、各4、4人、3场景、共同成功对象；高二寒假起 |
| 社恐 + 吉他手 | 后藤独 | 合计10、舞台、高压力表演、可信赖共同对象；高二起 |
| 完美主义 + 冰山 | 雪之下雪乃 | 合计10、学力16、直接帮助、关系摩擦；高二起 |

合成事件可以接受或延后。接受后来源仍显示，但普通来源选项停止出现，由隐藏结果接管。隐藏选项仍替换正常选项、消耗状态、允许失败。

## 癫佬重写

癫佬不再表示所有无厘头行为，也不再被固定塞进每局候选池。它现在集中于：

- “杀杀杀杀杀！先把它杀完”；
- 正式提出决斗；
- 用直尺选择武器；
- 宣布 Boss 战阶段；
- 把失败方案“砍断、切开、剁碎”再重组。

世界线、跳过前提归入电波；其他泛用网络抽象留给后续特质。虚构战斗本身不会造成现实伤害，但在严肃场合无视他人感受会降低关系与信任，并可能留下后续尴尬。

## 考试、成长与状态

- 学力每点贡献改为约13分，取消按学年自动加分。
- 考试范围从300～680扩为180～735，允许真实短板与高成长体现差异。
- 策略按钮显示预计分数区间、精力和压力代价。
- 成绩单显示试卷基准、当时学力、准备、身心、特质、习惯、策略与临场。
- 普通课程月不再自动赠送学力经验；学习行为、习惯、复习与考试回顾才成长。
- 精力与压力改为醒目状态条。精力不足的行动缺口会转成压力，压力溢出会继续损耗精力。
- 判定增加精力<10、压力≥90的第二级惩罚。

## 人物与点击

八名人物各自拥有独立初遇标题、场景和两种不同后果。初遇后不再立刻串接一场普通人物互动，自动三年流程相对旧版减少约10次点击，同时保留选择后的结果反馈。

人物仍使用“班长、同人女、体育生”等工作称呼。本版完成的是初遇与机制框架，不是八条完整人物剧情。

## 自动验证

`npm test` 当前通过：

- 34组规则回归；
- 8条从高一九月到高三六月的完整流程；
- 中途与毕业存档重放；
- 三条合成配方的独立门槛；
- 特质替换不继承原收益、来源接管与隐藏失败；
- 考试分布、构成与预览；
- 精力/压力溢出；
- 八个初遇唯一性与单事件结束；
- 随机池不固定癫佬、隐藏角色不进入开局。

固定流程样本的毕业分数范围为468～715，完整三年约266～287次按钮操作；这是自动策略样本，不代表自然玩家的唯一分布。

`npm run test:standalone` 用相同操作分别跑源码与单文件版，并比较最终状态与点击数。

## 已知限制

- 只有六项常规特质进入成长系统，其余特质仍主要影响既有事件或作为角色标签。
- 后藤独与雪之下雪乃的自然触发率需要更多真人存档；自动测试确认门槛可达，不代表当前密度已最终平衡。
- 高一仍有旧数组事件，部分动态函数的成本预览需要继续集中化。
- 人物初遇已去重，但后续每人每学年只有有限样板，仍可能感到关系线不够厚。
- 外貌用途少于四项可成长能力；本版没有增加永久改貌事件。
- 校园论坛是本地模板，不是在线内容，也不存在全服统计或自动上传。
- 自动测试不等于真实浏览器视觉验收。发布环境没有可用的 Playwright/Chromium 时，应另行在桌面与手机浏览器检查布局、JSON下载和PNG字体。
