# 特质成长与角色合成（0.6.0）

## 两层特质

- 常规特质来自开局候选池。当前癫佬、电波、社恐、吉他手、完美主义、冰山接入成长与专属选项。
- 隐藏特质不进开局池，全部以二次元角色命名，只能由两项常规特质和实际行为合成。
- 合成后来源仍显示在人物档案，但专属选项由隐藏特质接管。来源一局只能参与一次合成。

这是一套可继续扩写的框架，不表示其余常规特质永远不会成长。新增成长特质时，应增加独立选项组，不要把状态重新塞回共享的旧 `traitMilestones`。

## 专属选项如何出现

合适的人物社交场景会把一个标记为 `replaceable` 的普通主动选项改写为紫色特质选项：

- 一次事件至多改写一个选项，按钮总数不增加。
- 被替换选项的能力经验、关系、信任、项目收益不会暗中结算。
- `protected` 的安全回应、考试、合成确认、路线与毕业决定不参与替换。
- 多个可用特质会轮换出现；漏过一次后，下一个合适场景保底提供特质选项。
- 最近使用的模板会被避开，降低连续复读。

按钮会显示精力/压力成本与“可能改变关系”。专属选项也使用判定，因此同一句行为对不同人物、关系和严肃场合可以产生不同结果。

## 常规成长

| 等级 | 条件 |
| --- | --- |
| Lv.1 | 开局拥有 |
| Lv.2 | 4个不同自然月实际选择该特质 |
| Lv.3 | 8个不同自然月实际选择该特质 |

同一特质每个“学年:自然月”最多增加1点；同月多次选择仍产生关系、资源、失败与人物记录，但不重复刷成长。系统同时记录：

- 使用过的月份；
- 面对过的人物；
- 场景类型；
- 成功接住该表达的人物；
- 具体行为风格，例如决斗、演奏、间接表达、直接帮助；
- 失败次数，以及高压力下的舞台使用。

这些记录用于合成条件。单纯在状态中拥有两个特质不够。

## 三条角色合成

### 古明地恋

素材为癫佬 + 电波。要求双方至少4点、合计12点，覆盖4名人物和3类场景，并至少有同一人物成功接住过两种特质；最早在日历索引16，即高二寒假1月触发。

癫佬现为战斗脑：杀、决斗、选武器、Boss阶段、把失败方案砍碎重组。电波负责跳过前提、世界线与信号式思考。古明地恋把两者合成“决斗电波”，不再等同于旧版泛用抽象行为。

### 后藤独

素材为社恐 + 吉他手。要求双方至少3点、合计10点，覆盖至少2人和2类场景，有同一人物接住两种表达；此外必须发生过演奏/舞台行为、在压力≥55时仍尝试过一次表演，并拥有一位达到信任2或关系4的共同成功对象。最早高二触发。

获得后，表达更可能通过琴弦和舞台完成，但资源成本更高；它不删除紧张。

### 雪之下雪乃

素材为完美主义 + 冰山。要求双方至少3点、合计10点，覆盖至少2人和2类场景，有共同成功对象；学力至少16，出现过直接帮助，并发生过一次失败或低关系摩擦。最早高二触发。

获得后，帮助更准确、直接，成功收益较高；失败时“正确但伤人”的代价仍在。

## 接受、暂缓与锁定

条件满足后会出现专属合成事件：

- 接受：加入隐藏特质，记录来源、时间和合成历史；来源普通选项停止出现。
- 暂缓：压力小幅下降，至少两个月后才能再次触发；已有成长不丢失。
- 隐藏特质本身仍替换正常选项、消耗资源并允许大失败，不是数值上的无条件上位版本。

## 数据与接口

- `HIDDEN_TRAITS`：隐藏特质描述与来源。
- `TRAIT_CHOICE_SETS`：普通/隐藏选项模板、判定属性、关系结果和资源成本。
- `FUSION_RECIPES`：时间、成长、人物、场景和行为门槛。
- `S.traitJourneys[name]`：每个常规特质的独立成长记录。
- `S.hiddenTraitSources`、`S.fusionHistory`：已合成来源与历史。
- `fusionEligibility(id)`：返回每项门槛的布尔状态，便于测试与调试。

新增配方时必须同时验证：两个来源在开局池存在；隐藏结果不进入开局池；自然流程有机会满足条件；延后与接受都能继续月份；合成后来源不会继续竞争注入位置。
