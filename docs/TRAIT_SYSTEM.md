# 特质作用、成长与后天形成（0.6.1）

## 类型与功能分开

60项普通特质分为性格、技能、兴趣、生活、网络、命运；类型描述来源与气质。成长、后天形成、专属选项是另一组功能标识，不能把“成长”与“兴趣”混成互斥分类。

全部60项都有当前可执行的基础作用，但只有癫佬、电波、社恐、吉他手、完美主义、冰山六项拥有完整成长型专属选项和后天形成路径。基础作用不代表独立剧情线，也不代表每个圈层已有专属人物故事。

## 普通特质基础作用

- `TRAIT_PROFILES` 明确分类、能力关联、生效领域、判定修正、月间效果、额外消耗与前提。
- 正向普通特质判定加成合计最多+2，负向加成独立结算；不暗改2d6骰面。
- 部分效果有条件，例如慢热须面对熟悉的人、冰山须压力低于70；说明与判定明细要一致。
- 月间基础作用只调整精力、压力，不赠送能力经验；两项资源各自最多恢复6，每自然月只结算一次。生活习惯中的具体学习训练是另一套机制。
- 有额外消耗的特质，在当月首次真实进入相关判定时支付；同一结果不重复扣费，查看预测不扣费。
- 后天获得的特质同样有基础作用，参与隐藏合成后基础作用仍保留。

欧皇在实际活动/考试提供固定+1，计入正向+2上限。非酋提供固定-1；实际失败后获得该项能力经验+1，每月最多2次，仍受能力成长上限约束。外貌不能练习成长，因此外貌失败改为压力-2，与经验复盘共用两次额度。预测不产生失败奖励。

## 专属选项与机会成本

六项成长特质可出现在人物交流，也可进入已接入的学习、项目、创作、音乐、比赛和表演场景。活动必须指定真实领域与可替换位置，不能让弹吉他随机替代不适合音乐的任务。

- 一次事件至多改写一个 `replaceable` 普通主动选项，按钮数不增加。
- 原选项的经验、关系、信任、项目进展和旗标不再结算；专属行动只结算自己的效果。
- `protected` 的安全回应、考试策略/临场、路线、形成、合成和毕业决定不参与替换。
- 候选特质轮换，避开最近模板；漏过一次后，下个合适场景保底提供专属选项。
- 按钮预览资源与风险，结果独立结算；不是特别台词加原选项全部收益。

癫佬保持战斗脑和决斗气质，电波负责跳跃联想与省略前提。纸面关卡、直尺或虚构战斗不等于真的伤人，但无视严肃场合或对方感受仍有关系代价。

## 六项常规成长

| 等级 | 条件 |
| --- | --- |
| Lv.1 | 开局拥有或接受后天形成；成长经验从0开始 |
| Lv.2 | 实际选择该特质专属行动，累计4个不同自然月 |
| Lv.3 | 同上，累计8个不同自然月 |

同一特质每个“学年:自然月”最多成长一次。同月多次行动仍支付资源并产生后果与人物/场景记录，但不重复增长经验。社交与非社交活动共用该特质同一份旅程。

`S.traitJourneys[name]` 记录月份、人物、场景、成功对象、行为风格、失败与高压力表演。无NPC活动不能虚构人物或共同成功记录。六项成长线继续开放，不因对应旧隐藏结果暂停而撤掉。

## 后天形成不是提前成长

后天形成只为这六项提供路径，不自动推断人格。入口在普通人物互动与假期的可选“试一种自己的做法”：玩家主动进入，选择一次具体练习，取代原相处/假期行动；不额外赠送月份、不叠加原收益，也不增加每月强制任务。

| 规则 | 当前值 |
| --- | --- |
| 行为证据 | 至少4个不同月份，相关普通行动每月最多计1次 |
| 最早形成 | 日历索引6，即高一下3月 |
| 后天名额 | 一局最多2项，原3项开局特质保留 |
| 询问时机 | 月末最多一次，自选接受或暂缓 |
| 暂缓 | 无惩罚、不扣名额、保留证据；至少3个月后再问 |
| 接受后的成长 | Lv.1、0经验；形成前证据不兑换成长XP |

六项普通练习分别为纸面关卡挑战、跳跃联想短篇、预写短句后的小范围沟通、公用吉他练习、额外细节校对、说明边界并完成承诺，均不要求预先拥有特质。

只接受显式 `formationEvidence:["电波"]` 等元数据与核对过的稳定事件/选择ID白名单，不按文字子串或笼统标签推断。只休息、独处或上网不会形成社恐、电波、冰山。“社恐”是可拒绝的游戏用语，不是诊断。

`S.acquiredTraits` 单独存后天特质，不改开局池；`S.traitFormation[name]` 记录月份、证据、暂缓期限与获得时间；`S.traitFormationHistory` 保留接受/暂缓决定。`ownedTraitNames()` 统一读取开局与后天特质，避免新特质只显示却不生效。

## 仅开放古明地恋

素材为癫佬＋电波，条件同时满足：

- 两项各至少4个月实际成长。
- 两项实际使用月份的并集至少12个月，不只是XP相加达到12；同月各用一次仍只算一个合成月份。
- 覆盖至少4名人物、3类场景。
- 至少一名共同人物成功接住过两种来源表达。
- 最早日历索引16，即高二寒假1月。
- 尚未拥有结果，来源尚未参与合成，且不在暂缓期。

符合后出现专属事件。接受后记录来源与时间；暂缓至少2个月，已有成长保留；每项来源一局只能参加一次合成。

合成只接管来源的**社交专属选项**；学习、项目等普通活动中的来源模板继续可用，基础作用也不消失。来源仍留在档案，合成不能删除原已拥有的玩法。古明地恋仍替换普通选项并承担资源、关系与失败后果，不是无条件上位版本。

其他隐藏角色保留开发样板数据，但 `enabled:false`：不显示、不合成、不经调试启用、不进入毕业回收。停用的是隐藏结果，不是社恐、吉他手、完美主义或冰山的成长。

本版不新增群友映射，也不把头像自动视为扮演或人格证据。未来角色是否启用，应在本人愿意参与并确认可用素材之后另作设计。

## 维护与检查入口

| 接口/定义 | 用途 |
| --- | --- |
| `TRAIT_PROFILES` / `traitEffectDescription` | 分类和实际作用说明 |
| `traitActivityModifiers` / `applyTraitActivityOutcome` | 纯修正计算与真实结算分离 |
| `TRAIT_CHOICE_SETS` / `TRAIT_ACTIVITY_SETS` | 社交与普通活动模板 |
| `recordTraitUse` / `traitJourney` | 同月去重的常规成长 |
| `recordTraitFormationEvidence` / `traitFormationEligibility` | 普通行动证据与门槛 |
| `tryTraitFormation` / `traitFormationSummary` | 月末确认与可读进度 |
| `enabledFusionRecipes` / `activeHiddenTraitNames` | 各入口统一过滤禁用结果 |
| `fusionEligibility` / `fusionStatus` | 合成门槛与启用配方 |

改动特质需检查：实际入口可达、预览一致、替换不继承收益、跨月去重、预测无副作用、隐藏开关一致、后天特质接入旧规则、存档与单文件一致。执行 `npm test` 与单文件检查；自动测试不替代真人试玩和浏览器视觉验收。
