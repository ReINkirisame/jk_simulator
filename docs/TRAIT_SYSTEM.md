# 特质选项与古明地恋（0.5.1）

## 替换意味着代价

拥有癫佬时，合适的社交场景会把一个正常主动选项替换成紫色选项。按钮总数不增加；原选项的能力经验、信任、项目贡献等不会一并领取。玩家仍可选保留的安全回应或退出。

只有事件明确提供替换位，机制才运行：

- context 声明 allowTraitChoices、npc、npc/social 标签与 sceneCategory。
- 普通选项元数据声明 replaceable:true，role 为 social 或 bold。
- protected:true、未标记的选项、唯一的继续按钮不会被替换。
- 一次事件至多替换一个位置。考试、进化确认、毕业关系等关键决定不参加替换。

提示会说明被替换的原选项。机制不修改内容源数组，避免后续重访错误继承紫色选项。

## 成长与进化

| 阶段 | 条件 |
| --- | --- |
| 癫佬 Lv.1 | 开局拥有该特质 |
| 癫佬 Lv.2 | 4次有效月度成长 |
| 癫佬 Lv.3 | 8次有效月度成长 |
| 古明地恋事件 | 12次有效月度成长 + 4名不同人物 + 3类场景 + 时间门槛 |
| 时间门槛 | 最早高二寒假1月，calendarIndex为16 |
| 正式进化 | 在“大家已经习惯了”事件中选择接受 |

每个“学年:自然月”最多增加1点成长；同月多次选择仍会产生关系和状态后果，也能记录不同人物/场景，但不重复加经验。4次选择最多升到Lv.2，不能直接进化。

场景分为课堂、校园、社团、假期。月份、人物和场景同时达标后，还要经过时间检查。专属事件在月初和月末检查，因此可以在寒假当月满足前置并触发。暂缓后至少隔2个月再检查。

普通玩局的进化时间取决于实际行为，并非按月自动赠送。当前测试：持续选择路线在高二2月触发；间歇选择路线在高二6月触发。它们是固定种子样本，不是所有玩家的时间承诺。

## 风险结算

癫佬使用2d6，对比难度8。NPC适应度、已有关系、场合和进化会提供修正；表达、外貌不会变成万能加成。

| 判定 | 普通癫佬关系变化 | 古明地恋关系变化 |
| --- | ---: | ---: |
| 大失败 | -3 | -1 |
| 小失败 | -1 | 0 |
| 成功 | +1 | +1 |
| 特别成功 | +2 | +2 |

大失败另减1信任并增加压力；普通阶段会留下下次见面处理的尴尬。其余结果可缓解少量压力。古明地恋提供+3修正，但不取消失败，也不取消替换正常选项的机会成本。

## 触发与扩写

测试期候选池固定有癫佬。符合条件的场景基础出现概率为55%；错过一次后，下一个符合条件的场景保底出现。模板尽量避开最近用过的3条。

内容配置在 src/data/trait-choices.js，结算在 src/core/trait-system.js。新特质优先增加配置组与必要的集中处理器，不要在每个事件里硬编码。

0.5.1 的月度成长、里程碑和进化仍是癫佬专用实现。扩展第二种成长特质时，应先将这些状态按特质ID隔离；不要直接复用共享的 traitMilestones 或默认第一组进化配置。
