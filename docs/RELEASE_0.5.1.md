# 女高模拟器 0.5.1 · 习惯与传闻版

这一版建立在0.5.0完整三年流程和新版UI之上，不重做人物称呼或界面底层，重点让“高二试错、高三取舍”和“别人怎样记住你”真正进入玩法。

## 直接试玩

打开“女高模拟器-v0.5.1.html”即可离线运行。源码包解压后打开根目录 index.html，效果相同。游戏自动保存，并可手动导出JSON存档；毕业后还可以下载1080×1720的PNG生活档案。

0.5.1只读取同版本存档。旧版本文件不会被覆盖，仍可各自独立运行。

## 这次具体增加了什么

### 高二：选择一种真正会持续的生活

项目确定后，玩家分别选择学习方式、放学后的默认安排和恢复方式。它们不产生每日任务，而是在每个自然月自动结算一次。

习惯持续两个月以后稳定，才向考试或项目提供额外优势。高二1月、3月各有一次复盘机会，每次最多调整一项；更换会清空这一项的持续月数，并付出精力与压力的适应代价。固定见面还需要选定具体人物，之后确实会增加和她相遇、建立关系的机会。

### 高三：锁住已经形成的东西

高三9月仍然选择学业、创作、身体或关系的优先方向，但这次会同时锁定两项高二习惯，只留下与该优先方向对应的一项可调整。寒假只允许微调这一项，不能把最后一年当成免费洗点。

### 校园论坛与条件传闻

高二开始，侧栏论坛每月自动产生两条校园背景帖，用来表现同一时间里还有别的事发生。它们不要求点击，也不消耗考试和事件使用的随机序列。

本版有12条传闻，条件来自实际存档：例如考试成绩、共同项目、固定社团、与某人的长期联系、旧花灯、深夜上网或癫佬成长。满足条件后，玩家会从一个人物口中听见传闻，并选择顺势演绎、认真澄清或暂不回应。传闻随后进入论坛，也可能被最多两个不同人物在后续对话中提起。同一存档两条传闻之间至少间隔两个月。

这不是在线论坛，也没有伪造“其他真实玩家”。0.5.1的帖子来自本地模板，所有数据只留在当前存档。

### 可分享的毕业档案

毕业页面现在读取：

- 五项最终属性与起点；
- 特质、社团和路线；
- 三类生活习惯；
- 共同项目及完成情况；
- 最重要的几段关系；
- 本局真正出现过的传闻；
- 没有完成的事情；
- 根据整局状态生成的毕业寄语。

“下载毕业档案图片”会在本地生成PNG，不会自动上传或分享。

## 当前边界

1. 新系统提高了持续成长的收益，自动样本的考试分数整体高于0.5.0；数值是否过强仍需要真人试玩，而不是继续凭自动路线微调。
2. 论坛目前以世界背景为主，传闻回收只提供短文本；它还不能代替完整人物线或群像冲突。
3. 12条传闻是单局事件池，没有跨周目图鉴、全服统计或在线内容。稀有性来自条件组合，不使用恶意的极低概率。
4. 毕业PNG的数据层有自动检查，但本环境仍无法完成真实浏览器视觉验收；中文字体、超长名字、移动端下载需要实机确认。
5. 人物仍沿用旧称呼，高二项目仍有共享结构，人物专属后续和项目独有障碍仍是下轮扩充重点。
6. 存档仍使用确定性重放，只支持精确版本。任何会改变事件ID、随机调用或流程顺序的发布都应升级版本。
