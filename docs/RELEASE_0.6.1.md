# 女高模拟器 0.6.1 · 特质完善

本版在0.6.0界面和三年流程上调整，不新增群友映射或隐藏角色。

## 普通特质

- 保留60项开局普通特质，新增分类、实际作用、适用领域说明；候选仍随机抽10选3，不固定塞入癫佬。
- 基础作用包括对应活动检定修正、有限月间恢复及明确代价。正向特质检定修正合计最多+2，月间恢复不免费增加能力经验。
- 欧皇固定+1，不篡改骰子；非酋固定-1，失败可复盘获得相应能力经验，每月最多2次；外貌失败改为减压，不增长外貌。
- 癫佬、电波、社恐、吉他手、完美主义、冰山保留六条成长线；扩展至适合的学习、项目、音乐、表演、竞赛和创作场景。并非每项在每个场合都能用。
- 专属行动只替代一个明确开放的普通选项；原行动的经验、关系、剧情标记等不再结算。安全选项、考试策略、路线入口和项目交付等关键决定不被替换。
- 独处活动不制造NPC或虚假的共同经历。指定媒介的排练、修灯等不会被吉他演奏替换。

## 后天形成

在假期安排或熟人互动中，可主动选择“试一种自己的做法”。这是占用当前活动机会的可选入口，不新增每月必做菜单。

相关行为至少跨4个不同月份，最早高一下学期，才在月末询问是否形成特质。玩家可以接受，或无惩罚地暂缓至少3个月。一局最多后天新增2项，原来3项不被移除。

六条成长线都提供普通尝试，不要求开局已经拥有目标特质；休息、独处或上网本身不会被自动解释为性格。形成记录不折算成特质成长，接受后从Lv.1、0成长经验开始。能力练习经验和特质成长经验是两套不同记录。

## 只开放古明地恋

- 其他隐藏角色保留停用数据，但不在正常选项、合成、调试准备、角色徽章或毕业档案中启用。
- 古明地恋仍由癫佬＋电波合成；双方至少各4次成长，合计至少12次，实际使用月份的并集至少12个月，覆盖4名人物、3类场景，并存在接住过两种表达的共同成功对象。
- 最早高二寒假1月；同月同时用过两个来源也只算一个实际月份。
- 合成后社交专属选项由古明地恋接管；来源特质的普通活动选项和基础作用保留，避免合成后反而失去活动玩法。来源不能再次参与合成。

## 可读性与一致性

开局卡片区分普通作用与可成长能力；游戏内可展开“特质作用与成长”，查看作用、来源、等级和后天记录。特质替换按钮直接显示原选项、独立行动代价及尚未支付的当月被动费用，不只依赖鼠标悬停。

普通检定与特质检定统一读取身心状态、领域修正。考试保留0.6.0的学力与成绩公式、预计分数、简化选择流程；先计算成绩快照，再结算特质额外消耗和失败复盘，避免复盘升级反过来改变刚结束的成绩。

## 运行与存档

离线版“女高模拟器-v0.6.1.html”下载后用浏览器打开。源码包完整解压后打开根目录index.html，无第三方运行依赖。

本版使用独立存档键，只接受0.6.1存档。旧存档没有删除或覆盖，请继续用对应旧版本打开；由于操作重放路径变化，本版不迁移旧档。自动存档不可用时，可使用JSON导出、导入。

发行前执行：

- 9条完整34个月三年流程，各自验证中途与毕业存档重放。

这些是Node环境下的规则与DOM模拟测试，不等于浏览器视觉验收。本轮环境未安装浏览器内核，桌面/手机实际布局、PNG下载及本地存储权限需在真实浏览器复验；可选脚本tools/browser-check.js保留供已有Playwright与Chromium的环境使用。

60项拥有基础作用不等于60条完整独立剧情；主要成长仍是六项。原有8名人物称呼、重复事件和数值平衡仍可继续完善。隐藏角色的扩写暂缓，等本人愿意提供特点与设定后再讨论，不按头像替真人定性。

建议反馈附版本、种子、月份、事件标题、所选按钮及预期/实际结果；重点观察普通作用能否感知、后天形成是否打断节奏、专属选项是否值得付出机会成本。
